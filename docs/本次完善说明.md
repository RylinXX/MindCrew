## 二、新增模块速览

### 1. 客服中心（`/api/cs/**`、`/cs`、`/cs-console`、`/cs-settings`）
- 访客匿名问答，AI 先答、命中关键词转人工；AI 复用 `MindCrewAgent`，答案带来源
- 页面外观（标题/Logo/主题色/欢迎语/快捷问题/工作时间/知识库范围/满意度）由 `cs_config` 单行动态驱动，保存即生效
- 坐席工作台：会话列表筛选、认领、回复、转接、关闭、满意度与统计
- SSO：`appId + "\n" + externalUserId + "\n" + ts + "\n" + nonce` HMAC-SHA256 签名，±300s 时间窗 + Redis nonce 防重放 + 一次性 ticket 换 JWT；支持 internal（跳本站 `/cs`）/ external（跳客户客服页）两种模式，外部账号可自动建号映射
- 钉钉机器人：配置 AES 加密、回调验签、按发送人建会话并同步返回 markdown

### 2. 检索分析（`/api/v2/retrieval/**`、`/retrieval-analytics`）
- 总览：问答量、命中率、零结果率、兜底率、改写率、平均召回/重排、平均时延、成本、满意度
- 趋势（补零升序）、工具分布、知识库维度、低质量查询（零结果/兜底/点踩）+ 明细抽屉
- 明细可看完整 retrieval_log / reflection_log / agentTrace；支持 UTF-8 BOM CSV 导出（已防公式注入）

### 3. 数字员工交付物（`/api/v2/office/**`、`/deliverables`、Crew 导出按钮）
- Crew 调研报告 → PPTX（封面/目录/章节分页/页脚）或 DOCX（标题层级/列表/正文/页脚）
- 通用 Markdown → PPTX / DOCX
- 合同：采购合同 / 服务合同两个内置模板，字段校验 + 金额中文大写（到亿）
- 鉴权：仅任务发起人或 admin 可导出 Crew 交付物

### 4. AI 问数（`/api/v2/data-qa/**`、`/data-qa`）
- 指标：每日提问量、活跃用户、Token 用量、模型成本、响应时延、反馈满意度、知识库排行、热门问题、每日成本
- 安全模型：LLM 只输出 `{metric, days, limit, dimension}` JSON，SQL 全部为代码内固定模板（参数化），用户输入不拼 SQL；解析失败走关键词兜底；不支持的问法返回 400 + 指标清单

## 六、已知限制 / 建议后续

1. 钉钉回调是同步 RAG，模型慢时可能触发钉钉回调超时，建议后续改异步 + 主动发消息
2. SSO 建会话时 `cs_session.source_app_id` 未回填（需前端把 exchange 返回的 appId 带回或后端 ticket 暂存）
3. 公开客服页与既有 ChatView 一样用 `v-html` 渲染 Markdown，未接 sanitizer（公开入口暴露面更大，后续可加白名单清洗）
4. 检索分析 `days` 接口侧允许 1~365，超大数据量下为内存聚合（单次上限 days×500 行）
5. 客服 AI 记账在机器人账号 `cs_robot` 名下（成本核算显示为客服机器人），如需按访客/坐席拆分可后续加渠道维度
6. 项目内还保留历史 `MedConversation/MedMessage` 实体（同表映射），后续可统一收敛到 `Qa*` 实体
